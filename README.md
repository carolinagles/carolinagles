<h3>I like turning messy data into tools that people can use.</h3>

<p>I work across machine learning, natural language processing, data pipelines, statistics and dashboards. I came to data from <strong>anthropology and public administration</strong>, so I define the problem before choosing a method, and I measure every model on data it has not seen. Each project below links to the code, a live app or a report, and is explained step by step in my <a href="https://carolinagles.github.io/DataPortfolio/"><strong>Data Portfolio</strong></a>.</p>
